# Glossary

Plain-language definitions of the terms in the overview documents.

| Term | Meaning |
|---|---|
| SDK | Software development kit: a library developers use to build on a product. Here, the Splunk Python SDK |
| Public API | The functions, classes, and methods an SDK promises to developers |
| API snapshot | A saved list of every public name in the SDK with its signature. Comparing two snapshots shows what changed |
| Reference docs | Generated pages that list every feature of the SDK: names, inputs, outputs |
| Concept page | Explains how something works and when to use it |
| Procedure (how-to) | Step-by-step instructions for one task, with prerequisites and a way to verify the result |
| Tutorial | A guided, multi-step lesson that builds something |
| Example | A short, complete, runnable script that teaches one realistic scenario |
| Manifest | The plan file listing each guide and example, what it covers, and which features it must explain |
| Key symbol | A feature a page must both explain in its text and show in an example |
| `coderef` | A small tool that pulls named parts of an example file into a page when the site is built, so pages hold no pasted code |
| Region | A named section inside an example file that a page can pull in |
| Quality gate | A check that must pass before a draft is accepted |
| Advisory check | A check that lowers the score but does not block acceptance |
| Reviewer | A language model asked to score a draft for accuracy, clarity, teaching value, and completeness |
| Improvement loop | A limited number of revise-and-recheck passes that keeps the best version and stops when more passes stop helping |
| Justification report | A short page per item saying what was checked, what changed, why it stopped, and what was not checked |
| Human gate | The point where a person reviews before anything is published |
| Baseline | The unmodified starting copy of the SDK, kept so our additions are easy to see |
| Sphinx | The tool that builds the SDK's reference site from its code comments |
| GitHub Pages | A GitHub feature that hosts a static website straight from a repository |
| `llms.txt` | A simple index file that helps language models find and read a site's pages |
| Diátaxis | A widely used way to sort documentation into tutorials, how-to guides, reference, and explanation |
